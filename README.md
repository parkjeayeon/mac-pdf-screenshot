# PageCap

PDF 뷰어 화면을 "다음 페이지 → 영역 캡처 → 저장" 순서로 반복해서 페이지별 PNG로 저장하는 macOS 도구입니다.
Cmd+Shift+5로 한 장씩 찍던 작업을 자동으로 처리합니다.

화면에 보이는 그대로를 찍을 뿐이고, 뷰어나 문서 보호 기능에는 관여하지 않습니다.
캡처한 이미지는 해당 문서의 라이선스가 허용하는 범위에서만 사용하세요.

## 구성

| 경로 | 내용 |
|---|---|
| `Sources/PageCapCore/` | 공용 로직: 영역 선택 오버레이, 영역 캡처, 렌더링 완료 감지, 페이지 넘기기 |
| `Sources/PageCapApp/` | SwiftUI GUI 앱 |
| `Sources/pagecap/` | 명령줄 도구 |
| `scripts/build-app.sh` | `build/PageCap.app` 번들 생성 (CLI도 함께 빌드) |

## 요구 사항

- macOS 13 이상
- Xcode 또는 Command Line Tools (`xcode-select --install`), Swift 5.9 이상
- Acrobat 스크립트 방식을 쓰려면 Adobe Acrobat 또는 Acrobat Reader
  - 확인한 환경: Adobe Acrobat DC 26.002 앱을 **Adobe 로그인 없이** 사용 (번들 ID `com.adobe.Acrobat.Pro`)
  - 별도 설치한 Acrobat Reader 앱도 같은 스크립트 명령을 제공하지만, 실제로 실행해 보지는 않았습니다

## 빌드

```bash
./scripts/build-app.sh
# → build/PageCap.app        (GUI)
# → .build/release/pagecap   (CLI)
```

빌드하는 맥의 아키텍처로만 만들어집니다. Apple Silicon에서 빌드하면 Intel 맥에서는 실행되지 않습니다.

## 권한

처음 실행할 때 시스템 설정 → 개인정보 보호 및 보안에서 아래 권한을 켜야 합니다.
GUI는 `PageCap`에, CLI는 실행하는 터미널 앱에 권한을 줍니다.

| 권한 | 용도 |
|---|---|
| 화면 기록 | 영역 캡처. 켠 뒤 앱(또는 터미널)을 다시 실행해야 적용됩니다 |
| 손쉬운 사용 | 마우스·키 입력으로 페이지 넘기기, 시작 전 페이지 클릭 |
| 자동화 → Adobe Acrobat | Acrobat 스크립트 방식으로 페이지 넘기기 |
| 입력 모니터링 | "직접 눌러서 등록" 기능을 쓸 때만 |

빌드할 때마다 로컬용 임시(ad-hoc) 서명을 하므로, 다시 빌드하면 macOS가 다른 앱으로 인식해서 권한을 다시 켜야 할 수 있습니다.

## GUI 사용법

1. Acrobat에서 **보기 → 페이지 표시 → 단일 페이지 보기**로 바꾸고, ⌘0(페이지 맞추기)을 누른 뒤 시작할 쪽으로 이동합니다.
2. `build/PageCap.app`을 실행합니다.
3. **저장**에서 폴더와 시작 번호를 정합니다.
   - 시작 번호는 직접 입력하거나 **1부터**, **이어서**(폴더의 마지막 번호 다음) 버튼을 씁니다.
4. **캡처 방식**을 정합니다.
   - **한 쪽 보기**를 고르고 **영역 지정…**으로 페이지 영역을 드래그합니다.
   - **페이지 넘기기**는 **Acrobat 스크립트 (권장)**로 둡니다.
5. **캡처 시작**(⌘↩)을 누릅니다. 현재 쪽부터 마지막 쪽까지 찍고 자동으로 멈춥니다.

**중지**(⌘.)를 누르거나 다른 앱을 클릭하면 멈춥니다.
영역, 폴더, 넘기기 방식은 저장되어 다음에 앱을 열면 그대로 남아 있습니다.

파일명은 `001_capture.png` 형식입니다. 1쪽에서 시작하고 시작 번호를 1로 두면 파일 번호와 쪽 번호가 같아집니다.

## 페이지 넘기기 방식

| 방식 | 설명 |
|---|---|
| **Acrobat 스크립트 (권장)** | AppleScript로 영역 아래의 Adobe 앱(Acrobat 또는 Reader)에 쪽 번호를 지정해 이동합니다. 전체 쪽수를 알 수 있어 마지막 쪽에서 정확히 멈추고, 빈 쪽처럼 내용이 같아 보이는 쪽이 있어도 멈추지 않습니다. 영역이 2개면 2쪽씩 이동합니다 |
| 마우스 앞으로·뒤로 버튼 | 마우스 사이드 버튼 신호를 보냅니다 |
| →, ←, ↓, Page Down, 스페이스바 | 키 입력을 보냅니다 |
| 직접 눌러서 등록 | 뷰어 위에서 평소 넘기는 버튼이나 키를 한 번 누르면, 실제로 들어온 신호를 원본 그대로 저장했다가 재생합니다 |

- 모든 방식은 뷰어를 맨 앞으로 가져와서, 실제로 맨 앞이 된 것을 확인하고, 페이지를 한 번 클릭해 포커스를 준 다음 시작합니다.
- Acrobat 스크립트가 아닌 방식은 넘긴 뒤 **마지막 페이지 판정** 시간 동안 화면이 바뀌지 않으면 끝난 것으로 보고 멈춥니다.
- **넘기기 테스트** 버튼으로 한 쪽을 넘겨 보고 화면이 바뀌었는지 확인할 수 있습니다.

## 동작 방식

1. 넘긴 뒤 영역을 반복해서 캡처하다가, 이전 쪽과 다른 화면이 **두 번 연속 같게** 나오면 렌더링이 끝난 것으로 보고 저장합니다.
2. 비교는 PNG 파일 바이트가 아니라 디코딩한 픽셀 데이터로 합니다.
3. 캡처에는 macOS 기본 명령 `screencapture -x -R x,y,w,h`를 씁니다.
4. 영역 좌표는 주 모니터 좌상단을 원점으로 하는 포인트 단위입니다. 보조 모니터가 왼쪽이나 위쪽에 있으면 음수가 될 수 있습니다.

## CLI 사용법

```bash
.build/release/pagecap --help

# 영역을 드래그로 지정한 뒤 Acrobat 스크립트로 캡처
.build/release/pagecap --out ~/Pictures/icao-8896

# 영역만 지정하고 --region 인자 출력
.build/release/pagecap select

# 지정해 둔 영역으로, 이어서 번호 매기기
.build/release/pagecap --out ~/Pictures/icao-8896 --region -1376,207,1329,1719 --start 97
```

| 옵션 | 설명 |
|---|---|
| `--out DIR` | 저장 폴더 (기본: 현재 폴더) |
| `--regions N` | 드래그로 지정할 영역 수 (기본 1, 두 쪽 보기면 2: 왼쪽 → 오른쪽) |
| `--region x,y,w,h` | 영역 직접 지정 (여러 번 사용 가능, 저장 순서대로) |
| `--next ACTION` | `acrobat`(기본) \| `forward` \| `back` \| `right` \| `left` \| `down` \| `pagedown` \| `space` |
| `--start N` | 시작 번호 (기본 1) |
| `--max N` | 최대 넘김 횟수 (기본 2000) |
| `--timeout SEC` | 마지막 페이지 판정 시간 (기본 6) |
| `--overwrite` | 같은 이름의 파일 덮어쓰기 (기본은 기존 파일이 있으면 멈춤) |

## 다른 맥에서 쓰기

- **앱만 복사**: `build/PageCap.app`을 옮깁니다. 같은 아키텍처의 맥이어야 합니다.
  - 받아서 처음 열 때 막히면 우클릭 → **열기**를 누르거나 `xattr -dr com.apple.quarantine PageCap.app`을 실행합니다.
- **소스로 빌드**: 저장소를 받아 `./scripts/build-app.sh`를 실행합니다.
- 어느 방법이든 권한은 그 맥에서 다시 켜야 합니다.
- Acrobat 스크립트 방식에는 Adobe Acrobat 또는 Acrobat Reader가 필요합니다. Adobe 로그인은 필요 없습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 페이지가 안 넘어감 | 넘기기 방식을 **Acrobat 스크립트**로 바꾸고, 자동화 권한을 확인합니다 |
| 화면 캡처 실패, 빈 이미지 | 화면 기록 권한을 켠 뒤 앱을 다시 실행합니다 |
| "뷰어 창을 찾지 못했습니다" | 영역 아래에 Acrobat 창이 있는지, 창을 옮기지 않았는지 확인한 뒤 영역을 다시 지정합니다 |
| "맨 앞으로 가져오지 못했습니다" | Acrobat 창을 한 번 클릭한 뒤 다시 시작합니다 |
| "이미 있습니다" 오류로 멈춤 | 시작 번호를 바꾸거나 덮어쓰기를 켭니다 |
| 이미지가 흐림 | 화면에 보이는 해상도로 저장됩니다. 영역을 크게 잡고 확대 비율을 키웁니다 |
